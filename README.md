TechStore – Base de datos

Descripción del caso

TechStore es una tienda de tecnología que necesita organizar y administrar la información de sus ventas.

La base de datos permite registrar y relacionar las categorías de productos, los clientes, los productos disponibles y las ventas realizadas.

El modelo está compuesto por cuatro tablas principales:

Categorias: almacena las categorías de los productos.

Clientes: contiene los datos de los clientes.

Productos: registra los productos, sus precios, stock y categoría.

Ventas: almacena las ventas realizadas, relacionando clientes y productos.

Tecnologías utilizadas

SQL Server

SQL (DDL y DML)

Pasos para ejecutar el script

Abrir SQL Server Management Studio (SSMS).

Conectarse al servidor de SQL Server.

Abrir una nueva consulta.

Copiar el contenido del archivo ventas_tech_db.sql.

Pegar el código en la ventana de consulta.

Ejecutar el script haciendo clic en Execute o presionando F5.

Verificar que las tablas se hayan creado y que los datos se hayan insertado correctamente.

Archivo del proyecto

ventas_tech_db.sql: contiene las instrucciones para crear la base de datos, las tablas, insertar los registros y realizar las consultas de validación.
